# Requirements traceability

Every requirement in the assignment PDF (`takehome-C-originals-pump.pdf`, not committed), mapped
to where it is implemented, the automated test that proves it, and the verification result.

Paths are abbreviated:

- `engine/` is `packages/engine/`.
- `api/` is `apps/api/`.
- `web/` is `apps/web/`.

**What "Result" means.** "Pass" means the test passed in the final local run and in GitHub
Actions, which runs every suite on every push (see [`docs/QA.md`](QA.md)). "Live" means it was
also checked on https://pump-casino.onrender.com (see [`docs/DEPLOYMENT.md`](DEPLOYMENT.md)).
"Manual" marks a judgement no automated test can make; it says what was looked at.
